잘못된 값 (0 입력)

포모도로 설정
집중과 휴식 시간을 분 단위로 입력함
현재 값 집중 25분 / 휴식 5분
입력 예 25 / 50 / 5
Enter = 저장 Esc = 취소
집중(분) > 0
휴식(분) > 5
1 이상의 숫자만 입력할 수 있음.

0 이하 또는 숫자가 아닌 값은 거부하고 같은 화면에 남음

이 화면에서 사용자가 하는 일

  1. 집중 분과 휴식 분을 차례로 입력하고 Enter 로 저장함 (기본 25/5)
  2. 잘못된 값이면 오류 문구가 뜨고 같은 화면에서 다시 입력함
  3. Esc 를 누르면 저장하지 않고 포모도로로 돌아감
