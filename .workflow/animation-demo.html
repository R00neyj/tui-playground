애니메이션 예시 고르기

아래 영상은 실제 터미널 화면을 흉내 낸 미리보기임. 마음에 드는 배경 A~H와 전환 1~4의 글자를 알려주면 됨 (예: "배경 F, 전환 3"). F·G 는 디졸브 느낌, H 는 보내준 이미지 느낌의 새 안임.

홈 화면 배경

홈 박스 뒤 전체 화면에 깔리는 움직이는 배경임. 박스 안쪽은 불투명해서 글자는 그대로 읽힘.

화면 전환 (홈 → 종료 타이머 → 홈 …)

홈에서 앱을 열거나 Esc 로 돌아올 때 약 0.7초 동안 재생됨. 키를 누르면 바로 끝나게 할 수 있음.

16색 모드는 그라데이션을 쓸 수 없어서 계단처럼 보임. 트루컬러를 지원하지 않는 터미널에서는 이 모습으로 자동 대체함. 실제 터미널에서는 화면을 다시 그리는 속도(초당 약 30회)와 글꼴에 따라 조금 다르게 보일 수 있음.
