# F-10 스톱워치

[← Parent document](../02-spec.md)

- User: 시간을 재고 싶은 사람
- Purpose: 경과 시간을 재고 구간(랩)을 기록함
- Input: `Space` 시작/정지, `l` 랩, `r` 리셋, Esc 홈
- Behavior: 경과 시간을 0.1초 단위 큰 숫자로 표시. 랩을 누르면 구간 시간과 누적 시간을 목록에 추가하고 최근 3개를 보여줌
- Output/result: 경과 시간, 랩 목록(번호, 구간, 누적)
- Exceptions: 정지 중 `l` 은 무시. 측정 중 Esc 로 나가면 측정이 멈춤 (포모도로와 같은 확인 절차)
- Acceptance criteria:
  - [ ] 시작/정지/리셋이 동작함
  - [ ] 랩이 구간·누적 시간과 함께 기록됨
