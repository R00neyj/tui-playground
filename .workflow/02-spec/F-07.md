# F-07 시스템 모니터

[← Parent document](../02-spec.md)

- User: PC 상태를 보면서 작업하는 사람
- Purpose: CPU·메모리·디스크 사용량을 실시간으로 봄
- Input: `p` 일시정지/재개, `+` / `-` 갱신 주기 변경 (기본 1초), Esc 홈
- Behavior: 주기마다 값을 갱신. CPU·메모리는 막대와 최근 60회 추이(스파크라인), 디스크는 드라이브별 사용률, 가동 시간도 표시. 사용률 70% 이상이면 막대가 color.warn 으로 바뀜
- Output/result: 사용률 %, 사용량/전체(GB), 추이, 가동 시간
- Exceptions: 값을 읽지 못하면 "-" 와 한 줄 안내를 표시하고 앱은 계속 동작. 일시정지 중에는 값이 고정됨
- Acceptance criteria:
  - [ ] 주기마다 값이 갱신됨
  - [ ] `p` 로 일시정지/재개가 됨
  - [ ] 읽기에 실패해도 앱이 멈추지 않고 "-" 로 표시됨
