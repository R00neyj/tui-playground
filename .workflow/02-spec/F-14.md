# F-14 홈 꾸밈 (배경·전환·아케이드 조작부·설정)

[← Parent document](../02-spec.md)

- User: 이 프로젝트를 재미로 쓰는 사람
- Purpose: 홈과 앱 화면 뒤의 움직이는 배경, 화면 전환 효과, 키 입력에 반응하는 아케이드 조작부를 설정에서 고르고 끌 수 있음
- Input: 홈에서 `s` → ↑↓ 항목, ←→ 값 변경 (배경 A·B·C·E·H·끔, 전환 1~4·끔, 조작부 켬/끔). 기본값: 배경 H, 전환 3(디졸브), 조작부 끔
- Behavior: 바꾸는 즉시 적용·저장(사용자 설정 폴더 settings.json). 색 미지원 터미널·NO_COLOR·TUI_ANIM=off 면 효과 꺼짐. 조작부는 창 세로가 모자라면 자동으로 숨김. 앱 화면에도 배경과 조작부가 이어짐
- Output/result: 배경 위의 박스, 전환 효과, 조이스틱·Enter/Esc/숫자 버튼 움직임
- Exceptions: 설정 저장 실패 시 안내(이번 실행에는 적용 유지)
- Acceptance criteria:
  - [x] 배경 5종·전환 4종·조작부가 모든 테스트 창 크기와 색 모드 3종에서 줄 폭이 맞음
  - [x] 전환의 시작·끝 화면이 정확함, 아무 키나 누르면 전환이 끝남
  - [ ] 실제 터미널에서 끊김 없이 도는지는 사용자 확인 필요 (배경 H는 프레임당 약 121KB)
