# F-15 점심 룰렛

[← Parent document](../02-spec.md)

- User: 점심 메뉴를 못 정하는 본인·동료
- Purpose: 메뉴 목록이 슬롯머신처럼 돌다가 점점 느려지며 하나에서 멈춤. 재미용
- Input: Space/Enter 돌리기 (도는 중이면 바로 결과), ↑↓ 칸 이동, `a` 메뉴 추가, `d` 선택한 메뉴 삭제, Esc 홈 (입력 중 Esc 는 입력 취소)
- Behavior: 최소 두 바퀴를 돈 뒤 무작위 칸에서 멈춤. 간격은 40ms 에서 360ms 까지 느려짐. 메뉴는 `TUI-playground/lunch.json` (사용자 설정 폴더)에 저장하고, 파일이 없거나 깨졌으면 기본 메뉴 12개를 씀
- Output/result: 바퀴(선택 칸 + 앞뒤 메뉴), 상태 배지(대기/도는 중/결정), 결과 메시지
- Exceptions: 메뉴 없음 안내(돌리기 거부), 중복 이름 거부, 최대 30개·이름 14자, 저장 실패 시 이번 실행에서만 유지하고 경고
- Out of scope: 가중치, 외부 맛집 검색, 이력 기록
- Acceptance criteria:
  - [x] 돌리면 최소 두 바퀴를 돈 뒤 고른 칸에서 멈추고 간격이 점점 느려짐 (TestLunchSpin*)
  - [x] 옛 회전·다른 인스턴스의 틱이 새 회전에 섞이지 않음
  - [x] 추가·삭제가 파일에 저장되고, 모두 지운 빈 목록도 그대로 유지됨
  - [x] 모든 테스트 창 크기에서 박스가 깨지지 않고 창 높이를 넘지 않음
