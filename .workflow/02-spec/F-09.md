# F-09 Codex 사용량 모니터

[← Parent document](../02-spec.md)

- User: Codex CLI 를 쓰는 본인·지인
- Purpose: Codex 토큰 사용량을 F-08 과 같은 형식으로 봄 (읽기 전용)
- Input: ←/→ 기간 전환, `r` 새로고침, Esc 홈
- Behavior: Codex 가 남기는 사용 기록을 읽어 기간별 합계, 모델별 표, 최근 7일 막대를 보여줌. 이 PC 에는 `~/.codex` 가 없어서 기록 위치와 형식은 확인하지 못했음 → 구현 시 확인
- Output/result: F-08 과 같은 화면 구성
- Exceptions: 기록이 없는 것이 기본 상태일 수 있음 → "Codex 기록을 찾을 수 없음" 안내
- Acceptance criteria:
  - [ ] 기록이 있으면 기간별 합계가 표시됨
  - [ ] 기록이 없으면 안내 문구가 나오고 앱은 정상 동작함
