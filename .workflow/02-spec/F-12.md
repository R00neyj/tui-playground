# F-12 디스크 사용량 트리맵

[← Parent document](../02-spec.md)

- User: 어떤 폴더가 용량을 많이 차지하는지 한눈에 보고 싶은 사람
- Purpose: 폴더 크기를 사각형 면적으로 보여줌 (squarified treemap). 읽기 전용
- Input: 열면 홈 폴더를 스캔. `p` 다른 경로, `r` 다시 스캔, `c` 취소, `v` 맵/목록 전환, 방향키/hjkl 이동, Enter 폴더 안으로, Esc/Backspace 위로
- Behavior: 백그라운드 스캔(진행률 표시), 심볼릭 링크·정션은 따라가지 않음, 읽기 오류는 건너뛰고 개수를 셈. 창이 작으면 목록으로 자동 전환
- Output/result: 사각형(이름·크기), 선택 칸의 경로·크기·부모 대비 %
- Exceptions: 스캔 실패·취소·빈 폴더·접근 거부 안내. 크기는 겉보기 크기(디스크 할당 크기 아님)라고 화면에 표시
- Acceptance criteria:
  - [x] 사각형이 틈·겹침 없이 영역을 채우고 면적이 크기에 비례함 (TestSquarify*)
  - [x] 스캔이 취소되고 고루틴이 남지 않음
  - [x] 모든 테스트 창 크기에서 박스가 깨지지 않고 창 높이를 넘지 않음
  - [ ] 큰 드라이브(`C:\`) 전체 스캔 시간은 미확인 (사용자 프로필 폴더 104GB·파일 56만 개는 약 20초)
