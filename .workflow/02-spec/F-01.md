# F-01 홈 메뉴

[← Parent document](../02-spec.md)

- User: 모든 사용자
- Purpose: 미니앱을 골라 쓰고 다시 돌아옴
- Input: ↑/↓ 또는 숫자키로 선택, Enter 실행, Esc/q 종료
- Behavior: 등록된 앱을 한 줄씩(번호, 이름, 한 줄 설명) 나열함. 숫자키는 1~9 까지만 쓰고 그 이상은 ↑/↓ 와 Enter 로 고름. 앱 실행 중 Esc 를 누르면 홈으로 복귀. 인트로는 프로그램 시작 때 한 번만 보여줌. 종료 타이머 예약이 있으면 해당 줄 끝에 예약 상태와 남은 시간을 함께 표시함
- Output/result: 홈 ↔ 앱 화면 전환
- Exceptions: 등록된 앱이 없으면 "등록된 앱 없음" 표시, 창이 작으면 목록만 표시, 앱이 화면 높이를 넘으면 스크롤
- Acceptance criteria:
  - [ ] 목록에서 앱을 골라 실행할 수 있음
  - [ ] 앱에서 Esc 를 누르면 홈으로 돌아옴
  - [ ] 홈에서 Esc/q 로 프로그램이 종료됨
