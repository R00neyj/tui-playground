# F-16 멍때리기

[← Parent document](../02-spec.md)

- User: 잠깐 머리를 비우고 손으로 가지고 놀 것이 필요한 본인·동료
- Purpose: 피젯 스피너, 말랑이, 뽁뽁이 세 모드를 Tab 으로 바꿔가며 가지고 놂. 재미·스트레스 해소용이고 기록은 남기지 않음
- Input: Tab/Shift+Tab 모드 전환, Esc 홈. 모드별: 스피너 Space/↑ 튕기기·←→ 방향·r 초기화, 말랑이 Space 꾹·방향키 찌르기·그 외 글자키 콕, 뽁뽁이 Space 터뜨리기(커서는 그 자리에 머묾)·방향키 이동·r 새 판
- Behavior: 점자 캔버스(칸당 2x4 점)로 그리고 약 30fps 틱으로 움직임. 움직임이 끝나면 틱을 멈춤. 스피너는 최대 속도에서 약 7초, 한 번 튕기면 약 5초 뒤 멈춤. 말랑이는 꾹 누르면 약 1.2초 안에 1~2번 출렁이고 가라앉음. 뽁뽁이는 터지는 데 6프레임
- Output/result: 도형 본문, 상태 줄(회전수·속도 단계, 꾹/콕 횟수, 터뜨린 개수)
- Exceptions: 점자 폭이 어긋나는 글꼴은 `TUI_FIDGET=block` 으로 블록 문자 대체. 모드를 바꿔도 각 모드 상태는 유지되지만 비활성 모드는 멈춰 있음
- Out of scope: 소리, 마우스 조작, 기록·점수 저장
- Acceptance criteria:
  - [x] 세 모드 모두 모든 테스트 창 크기(최소 56x17)에서 박스가 깨지지 않고 창 높이를 넘지 않음
  - [x] 어떤 키 연타 뒤에도 유한 프레임 안에 움직임이 멈추고 틱이 끊김
  - [x] 스피너 최대 속도는 3중 대칭 앨리어싱 한계(60도/프레임) 아래로 제한됨
  - [x] 말랑이 밀림은 좌우·상하가 대칭이고 경계에서 속도가 죽음
  - [x] 뽁뽁이 방울이 점자 칸 경계에 맞아 커서 색이 이웃으로 번지지 않음
  - [ ] 실제 터미널에서 움직임이 부드러운지는 눈으로 확인하지 못함 (정지 프레임만 확인)
