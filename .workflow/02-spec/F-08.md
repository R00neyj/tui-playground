# F-08 Claude Code 사용량 모니터

[← Parent document](../02-spec.md)

- User: Claude Code 를 쓰는 본인·지인
- Purpose: 이 PC 의 Claude Code 토큰 사용량을 기간별로 봄 (읽기 전용)
- Input: ←/→ 기간 전환 (최근 5시간 / 오늘 / 이번 주), `r` 새로고침, Esc 홈
- Behavior: `~/.claude/projects/**/*.jsonl` 의 응답 기록(입력·출력·캐시 생성·캐시 읽기 토큰, 시각, 모델)을 합산함. 기간별 합계, 모델별 표, 최근 7일 일별 막대를 보여줌. 이 PC 기준 기록 파일이 475개라 첫 읽기는 진행 상태를 표시함
- Output/result: 토큰 합계(구분별), 모델별 표, 일별 막대
- Exceptions: 기록 폴더가 없거나 비어 있으면 안내 문구, 읽을 수 없는 줄은 건너뜀. 같은 응답이 중복 기록됐는지는 확인하지 못했음 → 구현 시 확인해서 중복 제거
- Out of scope: 플랜 한도 대비 남은 양과 금액 환산은 로컬 기록만으로 알 수 없어 표시하지 않음
- Acceptance criteria:
  - [ ] 기간별 토큰 합계가 구분별로 표시됨
  - [ ] 모델별 표와 최근 7일 막대가 표시됨
  - [ ] 기록이 없으면 안내 문구가 나오고 앱은 정상 동작함
  - [ ] 기록 파일을 읽기만 하고 수정하지 않음
