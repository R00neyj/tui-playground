# F-13 웹 브라우저(텍스트)

[← Parent document](../02-spec.md)

- User: 터미널 안에서 글(블로그, 문서, 뉴스)을 읽고 싶은 사람
- Purpose: 주소나 검색어를 넣으면 글 본문만 텍스트로 보여줌
- Input: 주소 또는 검색어(단어는 네이버 검색), ↑↓ 빠른 이동 목록 고르기, 번호 입력으로 링크 이동, `r` 다시, `h`/`l` 뒤/앞, `b` 빠른 이동에 저장, `m` 자바스크립트 렌더링 방식(자동·항상·끔), Esc 항상 홈
- Behavior: HTTP(S)로 받아 문자 코드(EUC-KR 등)를 변환하고 본문을 추출해 줄바꿈함. 네이버 블로그 글 주소는 본문 주소로 바꿔 읽음. 서버가 준 HTML에 글이 거의 없고 스크립트가 많은 페이지는 PC에 설치된 Chrome/Edge/Brave를 화면 없이 띄워 그린 결과에서 읽음(자동 모드)
- Output/result: 제목, 주소, 본문, 링크 번호, 진행 위치
- Exceptions: 페이지에서 온 글자는 제어문자를 모두 걸러냄. 다른 사이트로 가는 링크는 y/n 확인. 로그인·쿠키·이미지는 지원하지 않음. 브라우저가 없으면 자바스크립트 페이지는 읽지 못함
- Acceptance criteria:
  - [x] 위키백과·go.dev·네이버 뉴스/검색·네이버 블로그 글이 읽힘 (실제 접속으로 확인)
  - [x] 네이버 메인·다음 메인은 자바스크립트 렌더링으로 읽힘 (Chrome으로 확인: 블록 181개, 910개)
  - [x] 렌더링을 취소하면 브라우저 프로세스와 임시 폴더가 남지 않음 (실측)
  - [x] 제어문자·ESC가 화면에 닿지 않음 (TestBrInjection*)
  - [ ] 구글 검색 결과는 읽지 못함 (동의/봇 확인 화면이 나옴)
