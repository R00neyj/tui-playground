# F-11 할 일 목록

[← Parent document](../02-spec.md)

- User: 간단한 할 일을 적어두는 사람
- Purpose: 할 일을 추가하고 완료 체크하고 지움
- Input: `a` 추가(입력줄), ↑/↓ 이동, `Space` 완료 토글, `d` 삭제, Esc 홈
- Behavior: 항목을 `[ ]` / `[x]` 로 나열. 변경할 때마다 사용자 설정 폴더의 파일에 저장하고 다음 실행 때 다시 불러옴
- Output/result: 할 일 목록, 완료 개수
- Exceptions: 목록이 비면 안내 문구, 저장 실패 시 경고 표시(목록은 화면에서 계속 편집 가능)
- Acceptance criteria:
  - [ ] 추가, 완료 토글, 삭제가 동작함
  - [ ] 프로그램을 다시 실행해도 목록이 유지됨
